## Harnet — workbuddy agent, turn 2 (job workbuddy-git-1)

Turn 1 was merged into main by the human (`499503e`) before this turn started.

Implemented the worktree/delivery step (phase-1 step 2):
- `src/git/worktree.js`: open (git worktree add, `-b` only for a new branch),
  list (porcelain parser), abandon (kills the tmux session, keeps worktree +
  transcript), remove (optional --force / branch -D). Single exec() path that logs
  every command (argv, cwd, status) and turns non-zero exits into `GitError`.
  Runner is injectable, which is what makes the tests deterministic.
- `src/git/deliver.js`: `deliver()` merges child into parent with `--no-ff`; on
  conflict it reads unmerged files BEFORE `git merge --abort` (the abort wipes the
  index), never auto-resolves. Outcomes: merged / up-to-date / conflict / failed.
- Tests: `test/worktree.test.js`, `test/deliver.test.js` (fake runner, exact command
  sequences), `test/git-integration.test.js` (real git in a throwaway repo under
  os.tmpdir(), cleaned up in afterEach), `test/fake-runner.js` (shared helper).
  89/89 pass, stable over repeated runs; tsc strict + checkJs clean.
- Committed as `d248354` on `harnet/workbuddy`, not pushed.

Gotcha worth remembering: git prints real paths, and on macOS `/var` is
